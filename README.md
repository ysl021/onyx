# ONYX

Личный пульт управления музыкой для Android: медиаплеер, переключение вывода звука,
Galaxy Buds 3 Pro (шумодав, ANC на одно ухо, батареи), другие Bluetooth-наушники
и тексты Spicy Lyrics / Musixmatch / Genius / LRCLIB.

Чёрно-белый интерфейс, стекло, крупная типографика, OLED-фон, тёмная и светлая темы.

Репозиторий: [ysl021/onyx](https://github.com/ysl021/onyx) (public, GPLv3).
Релизы: [ysl021/onyx/releases](https://github.com/ysl021/onyx/releases).

Промо-видео: [promo/onyx-teaser.mp4](promo/onyx-teaser.mp4) — вертикальный тизер 1080×1920
для Telegram и GitHub Releases.

## Что уже умеет

- **Медиа**: play/pause, следующий/предыдущий, перемотка, прогресс, обложка, трек/артист/альбом.
  Работает с любым плеером через `MediaSessionManager` (Spotify, YouTube Music, локальные плееры).
- **Локальная музыка**: несколько папок через SAF, чипы «Все / Папка 1 / …», сканирование,
  обложки, поиск, очередь, фоновое воспроизведение через Media3/ExoPlayer. Название,
  исполнитель, альбом и обложку можно записать прямо в теги файла (mp3/flac/m4a/ogg)
  или хранить только внутри ONYX.
- **Кэш текстов**: найденные тексты и переводы сохраняются в памяти устройства и при
  повторном прослушивании открываются мгновенно, без обращения к сети.
- **Вывод звука**: переключение активного маршрута через `MediaRouter2.transferTo`.
- **Наушники**: Galaxy Buds (ANC/Ambient/Adaptive, одно ухо, батареи) и любые другие
  Bluetooth-наушники с именем/статусом/зарядом. Автоподключения к SPP нет.
- **Очередь**: отдельная вкладка, до 50 треков Spotify, тап по треку → играть,
  repeat, плейлисты Spotify с добавлением/удалением.
- **Эквалайзер**: системные пресеты, ручные полосы и умный **Auto** (3 зоны, ±3 дБ).
- **Визуализатор**: отдельная вкладка, FFT-спектр, waveform и плавная заглушка.
- **Spotify**: OAuth PKCE, очередь, repeat, плейлисты, активное устройство, Premium-подсказки.
- **Тексты**: Spicy Lyrics → Musixmatch → Spotify → LRCLIB → Genius; ручной поиск
  по названию/исполнителю, скролл без таймингов, перевод, чтение/караоке, точки пауз.
- **Темы**: тёмная/светлая/системная, анимированное переключение, «Внешний вид»,
  свой фон для каждой страницы, интенсивность, 10 шрифтов, цвет караоке.
  **Кастомные JSON-темы**: импорт, экспорт и простой редактор; примеры в `themes/`.
- **Иконки**: 10 встроенных вариантов иконки приложения (переключаются в настройках).
- **Язык**: русский / English с плавным переходом.
- **Анимации**: splash ONYX, переходы вкладок, press-анимации, Ken Burns обложки,
  стеклянный док с размытием.
- **Quick Settings**: плитки «Шумодав» и «ANC на одно ухо».

## Лицензия

ONYX распространяется под **GNU GPLv3** (см. `LICENSE`), потому что код SPP-протокола
Buds является производным от [GalaxyBudsClient](https://github.com/timschneeb/GalaxyBudsClient) (GPLv3).
При распространении APK исходники должны быть доступны.

## Секреты

Ключ Spicy Lyrics не хранится в репозитории. Для локальной сборки:

```powershell
Copy-Item secrets.properties.example secrets.properties
# вписать SPICY_KEY=sl_sk_...
```

`secrets.properties` добавлен в `.gitignore` и подставляется в `BuildConfig.SPICY_KEY`.

## Сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 35). Путь к SDK задан в `local.properties`.

```powershell
$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-17.0.21.9-hotspot"
.\gradlew.bat assembleDebug
```

APK: `app\build\outputs\apk\debug\app-debug.apk`

Релизная сборка (R8 + shrinkResources, подпись локальным debug-ключом для установки поверх):

```powershell
.\gradlew.bat assembleRelease
```

APK: `app\build\outputs\apk\release\app-release.apk`. Ключи в репозиторий не попадают.

Установка:

```powershell
& "D:\projekt ai\onyx\tools\android-sdk\platform-tools\adb.exe" install -r "app\build\outputs\apk\debug\app-debug.apk"
```

## Установка с GitHub (без сборки)

1. Открой [Releases](https://github.com/ysl021/onyx/releases).
2. Скачай `app-release.apk` последней версии.
3. Разреши установку из неизвестных источников и установи APK.
4. Обновления ставятся поверх: данные, темы, настройки и кэш текстов сохраняются.

Ничего клонировать, собирать или настраивать не нужно.

## Кастомные темы

Формат описан в `themes/*.json`. Минимальный пример:

```json
{
  "schema": 1,
  "id": "midnight",
  "name": "Midnight",
  "light": false,
  "background": "#050A18",
  "surface": "#0B1326",
  "text": "#EAF0FF",
  "accent": "#6FA8FF"
}
```

Импорт: Настройки → Внешний вид → Кастомные темы → «Импорт JSON». Там же можно
создать тему вручную, экспортировать её или удалить. Цвета обязаны быть в формате
`#RRGGBB` (или `#AARRGGBB`).

## Иконки

Настройки → Внешний вид → Иконка приложения. Доступно 10 встроенных вариантов.
Смена иконки может убрать значок с домашнего экрана — добавь ONYX заново из меню
приложений.

## Первый запуск

1. **Доступ к уведомлениям** — Настройки → Доступы → «Открыть». Без него приложение не видит,
   что играет. На некоторых прошивках Samsung пункт называется «Доступ к уведомлениям».
2. **Bluetooth-разрешения** — выдаются по кнопке в настройках (Android 12+).
3. **Батарея** — отключи оптимизацию, иначе система может убивать foreground-сервис наушников.
4. **Buds** — наушники должны быть сопряжены. Автоподключения нет: открой карточку
   «Наушники» и нажми «Подключить Buds». Если SPP-канал перехватывает Samsung-менеджер,
   выключи пакет (см. ниже) и нажми ↻.

### Galaxy Wearable / Samsung SPP

На Samsung SPP-канал постоянно занимает `com.samsung.accessory.paranmgr`. Пока он включён,
ONYX и Galaxy Wearable будут по очереди отбирать канал, и управление ANC будет мигать.
Для стабильной работы ONYX (однократно, через adb):

```powershell
adb shell pm disable-user --user 0 com.samsung.accessory.paranmgr
```

Вернуть обратно:

```powershell
adb shell pm enable com.samsung.accessory.paranmgr
```

Пока пакет выключен, Galaxy Wearable не сможет обновлять прошивку и менять настройки Buds;
аудио, сопряжение и ONYX работают.

## Spotify

1. Открой [Spotify Developer Dashboard](https://developer.spotify.com/dashboard), создай приложение.
2. В **Redirect URIs** добавь ровно:
   `http://127.0.0.1:8899/callback`
3. В настройках ONYX вставь **Client ID**, сохрани и нажми «Войти».
4. Откроется браузер; после подтверждения Spotify вернёт тебя в приложение.
   Очередь и повтор требуют **Premium** и активного устройства воспроизведения.
   Вход выполняется в фоне (не в экране настроек), поэтому сворачивание приложения
   и пересоздание Activity не обрывают ожидание callback. Если Custom Tab недоступен,
   ONYX откроет обычный браузер. Порт `8899` должен быть свободен.

Скоупы: `user-read-playback-state user-modify-playback-state user-read-currently-playing`.

## Тексты Spicy Lyrics

Основной источник — публичный API Spicy Lyrics (community TTML). Ключ **не хранится в git**:
он подставляется при сборке из `secrets.properties` в `BuildConfig.SPICY_KEY`. В настройках
ONYX поля для ключа больше нет.

Получить/заменить ключ: [developers.spicylyrics.org](https://developers.spicylyrics.org).
Если ключ пустой или отклонён, ONYX автоматически уходит на Musixmatch → Genius → LRCLIB.
Для треков не из Spotify поиск идёт через `/v1/tracks/search` по названию/артисту/длительности.

## Локальная музыка

1. Настройки → «Локальная музыка» → «Добавить папку» (или вкладка «Музыка»).
2. Можно добавить сколько угодно папок; в «Музыке» появятся чипы `Все · Папка 1 · …`.
3. Android выдаёт доступ только к выбранным папкам (SAF), без разрешения на всё хранилище.
4. ONYX сканирует `.mp3`, `.flac`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.wav` и читает метаданные.
5. Воспроизведение — Media3 ExoPlayer + MediaSessionService: фон, уведомление, Bluetooth-кнопки.
6. Поддерживаются поиск, очередь, shuffle/repeat, обложки и мини-плеер.

## Эквалайзер и визуализатор

- **Эквалайзер**: Настройки → «Звук» → «Открыть эквалайзер». Пресеты устройства + ручные полосы.
  Эффект общий для активного аудиовыхода; на части Bluetooth-устройств может быть недоступен.
- **Визуализатор**: отдельная вкладка. Нужен доступ к микрофону (так Android отдаёт аудиопоток).

## Структура

```
app/src/main/java/app/onyx/
  AppController.kt         — связывает медиа, маршруты, Spotify, тексты, звук, локальный плеер
  MainActivity.kt          — edge-to-edge, разрешения, запуск
  OnyxApp.kt               — навигация, глобальный фон, splash
  core/                    — DataStore-настройки, OkHttp
  media/                   — MediaSession, NotificationListener, MediaRouter2, заряд BT-наушников
  buds/                    — SPP-протокол, RFCOMM-клиент, foreground-сервис
  spotify/                 — OAuth PKCE (app-scoped), токены, очередь, повтор
  lyrics/                  — Spicy Lyrics, Musixmatch, Spotify, Genius, LRCLIB, перевод, кэш
  music/                   — SAF-библиотека, Media3 ExoPlayer, MediaSessionService
  audio/                   — эквалайзер и визуализатор
  ui/                      — темы, стеклянные компоненты, экраны
```

## Ограничения

- Переключение вывода — только смена маршрута. Полного disconnect/подключения Bluetooth нет.
- **Двойное прослушивание** (два независимых выхода) публичным Android API не поддерживается.
  На Samsung используй «Dual audio» в Sound Assistant; ONYX управляет активным маршрутом.
- **Spotify Canvas** официально не отдаётся Web API. Вместо него обложка на главной
  получила минималистичный Ken Burns-эффект.
- **Сторонние темы и иконки** пока не внедрены: есть 10 встроенных шрифтов, свои фоны,
  цвет караоке и темы оформления. JSON-темы/иконки — следующий этап.
- **ANC других наушников**: универсального протокола нет. Для Arctis Nova Pro управление
  ANC идёт через SteelSeries; ONYX показывает медиа-контроль и батарею.
- **BPM-синхронизация текста** без таймкодов исследована, но не внедрена: нужен надёжный
  beat-детектор и проверка на реальных треках.
- Управление ANC/батареями — только для Galaxy Buds. Остальные наушники — стандартный
  Bluetooth-аудиовыход; заряд показывается, если система транслирует его в BATTERY_LEVEL_CHANGED.
- Протокол Buds неофициальный: прошивки могут менять смещения полей. Если батареи/режим
  показываются неверно — пришли лог, поправим offsets в `BudsClient.parseStatus`.
- Spicy Lyrics — сторонний catalogue; при недоступности API остаются Musixmatch/Spotify/LRCLIB.
- Spotify color-lyrics может требовать client-token веб-плеера; при отказе используется LRCLIB.
