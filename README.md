# ONYX

Личный пульт управления музыкой для **Android и Windows**: медиаплеер, переключение вывода звука,
Galaxy Buds 3 Pro (шумодав, ANC на одно ухо, батареи), другие Bluetooth-наушники,
тексты Spicy Lyrics / Musixmatch / Genius / LRCLIB и синхронизация телефона с ПК.

Чёрно-белый интерфейс, стекло, крупная типографика, OLED-фон, тёмная и светлая темы.

Текущая версия Android — **0.9.3**. В репозитории:

- **Android** — Kotlin/Compose, `app/`, основная версия для телефона.
- **Windows (Rust + Tauri + Svelte)** — `desktop-rs/`, новый ПК-клиент; каркас уже
  собирается в MSI/NSIS, плеер и хаб переносятся по этапам.

Репозиторий: [ysl021/onyx](https://github.com/ysl021/onyx) (public, GPLv3).
Релизы: [ysl021/onyx/releases](https://github.com/ysl021/onyx/releases).

Промо-видео: [promo/onyx-teaser.mp4](promo/onyx-teaser.mp4) — вертикальный тизер 1080×1920
для Telegram и GitHub Releases.

## Версии, обновления и миграция

- **0.9.3** — текущий релиз. Эксклюзивный набор из 11 иконок в коллаборации
  с художницей: отдельная группа `EXCLUSIVE` в выборе иконки, анимация в превью
  и в интро. Плюс мелкие правки интерфейса.
- **0.9.2** — плейлисты с загрузкой, навигация по альбомам, импорт плейлистов.
- **0.9.0** — первый релиз на отдельном release-ключе. Встроенное автообновление:
  проверяет `android.json` на GitHub Releases, качает APK, сверяет SHA-256
  и ставит через `PackageInstaller`.
- **0.8.10** — переходная сборка (pre-release). Подписана старым debug-ключом,
  поэтому встаёт поверх 0.8.9 без удаления. Нужна только для экспорта данных
  перед переходом на 0.9.0; автообновление в ней отключено.

### Переход с 0.8.x на 0.9.0

Смена подписи означает, что 0.9.0 не встанет поверх старой debug-версии.
Один раз нужно переустановить приложение:

1. Установи **0.8.10** поверх текущей версии.
2. Настройки → Основные → Данные → **Экспорт данных**, сохрани JSON.
3. Удали ONYX.
4. Установи **0.9.0**.
5. Настройки → Основные → Данные → **Импорт данных**, выбери JSON и подтверди замену.
6. Заново добавь папки с музыкой: Android отзывает доступ к SAF-папкам при удалении.
7. Дальше обновления приходят сами, переустанавливать больше не нужно.

## Что уже умеет

- **Медиа**: play/pause, следующий/предыдущий, перемотка, прогресс, обложка, трек/артист/альбом.
  Работает с любым плеером через `MediaSessionManager` (Spotify, YouTube Music, локальные плееры).
- **Локальная музыка**: несколько папок через SAF, чипы «Все / Папка 1 / …», сканирование,
  обложки, поиск, очередь, фоновое воспроизведение через Media3/ExoPlayer. Название,
  исполнитель, альбом и обложку можно записать прямо в теги файла (mp3/flac/m4a/ogg)
  или хранить только внутри ONYX.
- **Плейлисты**: свои плейлисты и папки с обложками, drag-reorder, мультивыбор треков
  в «Музыке» (long-press) и добавление в плейлист. Переключатель «Spotify | Мои».
- **YouTube**: отдельная вкладка — поиск, вставка ссылки, разбор таймкодов из описания,
  скачивание аудио и **физическая нарезка** микса на отдельные треки прямо в SAF-папку.
  Каждый отрезок получает теги и обложку, затем появляется в «Музыке» и в плейлисте
  с именем видео.
- **Открытые источники**: Openverse, Internet Archive и ccMixter в том же поиске —
  только аудио с открытой лицензией. Результат уже является прямым файлом: можно
  слушать сразу или скачать в SAF-папку; лицензия и страница автора видны у каждого трека.
- **Таймер сна**: 15/30/45/60 минут на главной — по истечении ставит на паузу и Spotify,
  и локальный плеер.
- **Свайпы**: горизонтальный свайп на странице переключает вкладки (например, «Плеер ↔ Текст»).
- **Кэш текстов**: найденные тексты и переводы сохраняются в памяти устройства и при
  повторном прослушивании открываются мгновенно, без обращения к сети.
- **Вывод звука**: переключение активного маршрута через `MediaRouter2.transferTo`.
- **Наушники**: Galaxy Buds (ANC/Ambient/Adaptive, одно ухо, батареи) и любые другие
  Bluetooth-наушники с именем/статусом/зарядом. Автоподключения к SPP нет.
- **Очередь**: отдельная вкладка, до 50 треков Spotify, тап по треку → играть,
  repeat, плейлисты Spotify с добавлением/удалением.
- **Эквалайзер**: системные пресеты, ручные полосы и умный **Auto** (3 зоны, ±3 дБ).
- **Визуализатор**: отдельная вкладка, FFT-спектр, waveform и плавная заглушка.
- **Spotify**: OAuth PKCE, очередь, repeat, плейлисты, активное устройство, Premium-подсказки.
- **Тексты**: Spicy Lyrics → Musixmatch → Spotify → LRCLIB → Genius; ручной поиск
  по названию/исполнителю, скролл без таймингов, перевод, чтение/караоке, точки пауз.
- **Темы**: тёмная/светлая/системная, анимированное переключение, «Внешний вид»,
  свой фон для каждой страницы, интенсивность, 10 шрифтов, цвет караоке.
  **Кастомные JSON-темы**: импорт, экспорт и простой редактор; примеры в `themes/`.
- **Иконки**: 10 встроенных вариантов и 11 эксклюзивных в коллаборации
  с художницей — отдельная группа `EXCLUSIVE` в выборе иконки, с анимацией
  в превью и в интро (переключаются в настройках).
- **Язык**: русский / English с плавным переходом.
- **Анимации**: splash ONYX, переходы вкладок, press-анимации, Ken Burns обложки,
  стеклянный док с размытием.
- **Quick Settings**: плитки «Шумодав» и «ANC на одно ухо».
- **Обновления**: встроенная проверка `android.json`, скачивание APK, SHA-256 и
  установка через `PackageInstaller`; онбординг при первом запуске.
- **Данные**: экспорт/импорт плейлистов, избранного и настроек в JSON.
- **Связка с ПК**: LAN-хаб (TCP 8787 + UDP 8788), передача плейлистов/лайков,
  локальных файлов и presence; Discord Rich Presence на ПК.
- **Windows-клиент (в разработке)**: Rust + Tauri + Svelte (`desktop-rs/`),
  каркас уже собирается в MSI/NSIS.

## Секреты

В готовом APK ключ Spicy Lyrics уже встроен — пользователям собирать ничего не нужно.
В репозитории ключа нет: он подставляется при сборке из `secrets.properties`
(файл в `.gitignore`) в `BuildConfig.SPICY_KEY`. Это нужно только для локальной
сборки из исходников.

```powershell
Copy-Item secrets.properties.example secrets.properties
# вписать SPICY_KEY=sl_sk_...
```

`secrets.properties` добавлен в `.gitignore` и подставляется в `BuildConfig.SPICY_KEY`.

## Сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 35). Путь к SDK задан в `local.properties`.

```powershell
$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-17.0.21.9-hotspot"
.\gradlew.bat assembleDebug
```

APK: `app\build\outputs\apk\debug\app-debug.apk`

Релизная сборка (R8 + shrinkResources, подпись отдельным release-ключом):

```powershell
.\gradlew.bat assembleRelease
```

APK: `app\build\outputs\apk\release\app-release.apk`.

Подпись настраивается через `keystore.properties` (в `.gitignore`):

```properties
storeFile=keystore/onyx-release.jks
storePassword=...
keyAlias=onyx
keyPassword=...
```

Переходная сборка 0.8.10, которая должна встать поверх старой debug-версии:

```powershell
.\gradlew.bat assembleRelease -PdebugSigning
```

Версия хранится в `version.properties` (`versionName`). `versionCode` считается
из неё: `major*1_000_000 + minor*1_000 + patch` (0.9.0 → 9000).

YouTube-вкладка использует [NewPipeExtractor](https://github.com/TeamNewPipe/NewPipeExtractor)

```powershell
git clone --depth 1 --branch v0.27.0 https://github.com/TeamNewPipe/NewPipeExtractor.git
cd NewPipeExtractor
.\gradlew.bat :extractor:jar
copy extractor\build\libs\extractor-v0.27.0.jar ..\app\libs\NewPipeExtractor-0.27.0.jar
```

Установка:

```powershell
& "D:\projekt ai\onyx\tools\android-sdk\platform-tools\adb.exe" install -r "app\build\outputs\apk\debug\app-debug.apk"
```

## Установка с GitHub (без сборки)

1. Открой [Releases](https://github.com/ysl021/onyx/releases).
2. Скачай `app-release.apk` последней версии.
3. Разреши установку из неизвестных источников и установи APK.
4. Дальше ONYX сам проверяет `android.json` и предлагает обновление; данные,
   темы, настройки и кэш текстов сохраняются.
5. Если ставишь **0.9.0 впервые поверх 0.8.x** — сначала установи 0.8.10,
   экспортируй данные, удали приложение и поставь 0.9.0
   (см. «Переход с 0.8.x на 0.9.0»).

Ничего клонировать, собирать или настраивать не нужно.

> После смены иконки или крупного обновления значок ONYX на рабочем столе может
> исчезнуть: система привязывает его к старому компоненту. Добавь ONYX заново из
> меню приложений — данные и настройки сохранятся.

## Кастомные темы

Формат описан в `themes/*.json`. Минимальный пример:

```json
{
  "schema": 1,
  "id": "midnight",
  "name": "Midnight",
  "light": false,
  "background": "#050A18",
  "surface": "#0B1326",
  "text": "#EAF0FF",
  "accent": "#6FA8FF"
}
```

Импорт: Настройки → Внешний вид → Кастомные темы → «Импорт JSON». Там же можно
создать тему вручную, экспортировать её или удалить. Цвета обязаны быть в формате
`#RRGGBB` (или `#AARRGGBB`).

## Иконки

Настройки → Внешний вид → Иконка приложения. Доступно 10 встроенных вариантов
и 11 эксклюзивных — группа `EXCLUSIVE`, в коллаборации с художницей. У эксклюзивных
иконок есть собственная анимация в превью и в интро при запуске; ярлык на рабочем
столе статичен, потому что Android не поддерживает живые launcher-иконки.
Смена иконки может убрать значок с домашнего экрана — добавь ONYX заново из меню
приложений.

Исходники эксклюзивного набора лежат в `promo/artist-icons/`, а скрипт
`promo/artist-icons/build.py` пересобирает из них ресурсы (`drawable-xxxhdpi`):
чёрный фон вырезается в прозрачность, знак вписывается в safe zone adaptive-иконки.

```powershell
py -3 promo/artist-icons/build.py --src "D:\ishodniki"
```

## Первый запуск

1. **Онбординг** — при первом запуске ONYX сам предложит три шага: доступ к
   уведомлениям, папка с музыкой и разрешение на установку обновлений.
2. **Доступ к уведомлениям** — Настройки → Доступы → «Открыть». Без него приложение не видит,
   что играет. Если переключатель серый (Android 13+): Настройки приложения → ⋮ →
   «Разрешить ограниченные настройки», затем включить доступ.
3. **Bluetooth-разрешения** — выдаются по кнопке в настройках (Android 12+).
4. **Батарея** — отключи оптимизацию, иначе система может убивать foreground-сервис наушников.
5. **Buds** — наушники должны быть сопряжены. Автоподключения нет: открой карточку
   «Наушники» и нажми «Подключить Buds». Если SPP-канал перехватывает Samsung-менеджер,
   выключи пакет (см. ниже) и нажми ↻.

### Galaxy Wearable / Samsung SPP

На Samsung SPP-канал постоянно занимает `com.samsung.accessory.paranmgr`. Пока он включён,
ONYX и Galaxy Wearable будут по очереди отбирать канал, и управление ANC будет мигать.
Для стабильной работы ONYX (однократно, через adb):

```powershell
adb shell pm disable-user --user 0 com.samsung.accessory.paranmgr
```

Вернуть обратно:

```powershell
adb shell pm enable com.samsung.accessory.paranmgr
```

Пока пакет выключен, Galaxy Wearable не сможет обновлять прошивку и менять настройки Buds;
аудио, сопряжение и ONYX работают.

## Spotify

1. Открой [Spotify Developer Dashboard](https://developer.spotify.com/dashboard), создай приложение.
2. В **Redirect URIs** добавь ровно:
   `http://127.0.0.1:8899/callback`
3. В настройках ONYX вставь **Client ID**, сохрани и нажми «Войти».
4. Откроется браузер; после подтверждения Spotify вернёт тебя в приложение.
   Очередь и повтор требуют **Premium** и активного устройства воспроизведения.
   Вход выполняется в фоне (не в экране настроек), поэтому сворачивание приложения
   и пересоздание Activity не обрывают ожидание callback. Если Custom Tab недоступен,
   ONYX откроет обычный браузер. Порт `8899` должен быть свободен.

Скоупы: `user-read-playback-state user-modify-playback-state user-read-currently-playing`.

## Тексты Spicy Lyrics

Основной источник — публичный API Spicy Lyrics (community TTML). В release-APK ключ
уже встроен; в git его нет — для локальной сборки он берётся из `secrets.properties`
и попадает в `BuildConfig.SPICY_KEY`. В настройках ONYX поля для ключа нет.

Получить/заменить ключ: [developers.spicylyrics.org](https://developers.spicylyrics.org).
Если ключ пустой или отклонён, ONYX автоматически уходит на Musixmatch → Genius → LRCLIB.
Для треков не из Spotify поиск идёт через `/v1/tracks/search` по названию/артисту/длительности.

## Локальная музыка

1. Настройки → «Локальная музыка» → «Добавить папку» (или вкладка «Музыка»).
2. Можно добавить сколько угодно папок; в «Музыке» появятся чипы `Все · Папка 1 · …`.
3. Android выдаёт доступ только к выбранным папкам (SAF), без разрешения на всё хранилище.
4. ONYX сканирует `.mp3`, `.flac`, `.m4a`, `.aac`, `.ogg`, `.opus`, `.wav` и читает метаданные.
5. Воспроизведение — Media3 ExoPlayer + MediaSessionService: фон, уведомление, Bluetooth-кнопки.
6. Поддерживаются поиск, очередь, shuffle/repeat, обложки и мини-плеер.

## YouTube

Вкладка **YouTube** (иконка библиотеки в нижнем доке) умеет:

1. **Поиск** по названию трека/микса/канала или **вставку ссылки** (`youtube.com/watch`,
   `youtu.be`, `/shorts/`, `/live/` или просто 11-символьный id).
2. **Таймкоды** берутся из глав/описания видео: `0:00`, `00:00`, `(3:21)`, `[7:40]`,
   `1:02:03`. Строки без таймкода и проза вроде «Recorded 12:30 in Berlin» игнорируются.
   Если в описании ничего не нашлось — таймкоды можно вставить вручную.
3. **Нарезка**: сначала один раз скачивается аудио (m4a/AAC), затем каждый выбранный
   отрезок вырезается без перекодирования (`MediaExtractor` + `MediaMuxer`) в отдельный
   файл. Это настоящие файлы, а не виртуальные клипы — их видят любые плееры.
4. **Сохранение**: кнопка папки сверху → выбрать SAF-папку. Внутри неё создаётся
   подпапка с названием видео, файлы получают имена `01 - Название.m4a`, теги
   (название/исполнитель/альбом) и обложку видео. Папка автоматически добавляется
   в локальную библиотеку; после скачивания создаётся плейлист с именем видео.
5. **Очередь**: скачивание идёт в foreground-сервисе `dataSync` с уведомлением
   о прогрессе, поэтому можно свернуть приложение. Кнопка со списком в шапке
   открывает очередь: там видно каждый отрезок и стрелками можно поднять его
   приоритет. Завершённые задачи убираются сами.
6. **История**: кнопка с часами показывает всё, что уже скачано; корзина удаляет
   файл с телефона (и из библиотеки). Там же можно скачать микс **целиком** —
   одной кнопкой «Целиком», без нарезки.
7. **Скорость**: большие файлы качаются четырьмя параллельными Range-запросами,
   что обходит обычное ограничение одного соединения YouTube.

Ограничения: нужен интернет, а YouTube иногда ограничивает выдачу для сторонних
клиентов. Если появляется «Подтвердите, что вы не робот», ONYX автоматически
пробует мобильные innerTube-клиенты; если и они закрыты — повтори позже.
Длинные видео скачиваются целиком перед нарезкой, поэтому нужно свободное место
в кэше.

## ПК-версия (Windows, в разработке)

- `desktop-rs/` — новый клиент на Rust + Tauri + Svelte 5. Сейчас собирается
  каркас: окно, тема, навигация, настройки, MSI/NSIS. Плеер на mpv, хаб,
  Discord и автообновление переносятся по этапам.
- Хаб: TCP 8787 + UDP 8788. Телефон и ПК должны быть в одной Wi-Fi сети.
- Discord: вторая строка — исполнители, альбом — только во всплывающей
  подсказке обложки.

## Эквалайзер и визуализатор

- **Эквалайзер**: Настройки → «Звук» → «Открыть эквалайзер». Пресеты устройства + ручные полосы.
  Эффект общий для активного аудиовыхода; на части Bluetooth-устройств может быть недоступен.
- **Визуализатор**: отдельная вкладка. Нужен доступ к микрофону (так Android отдаёт аудиопоток).

## Ограничения

- Переключение вывода — только смена маршрута. Полного disconnect/подключения Bluetooth нет.
- **Двойное прослушивание** (два независимых выхода) публичным Android API не поддерживается.
  На Samsung используй «Dual audio» в Sound Assistant; ONYX управляет активным маршрутом.
- **Spotify Canvas** официально не отдаётся Web API. Вместо него обложка на главной
  получила минималистичный Ken Burns-эффект.
- **Темы и иконки**: есть 10 встроенных шрифтов, свои фоны, цвет караоке,
  темы оформления и 21 иконка приложения (10 встроенных + 11 эксклюзивных).
  Импорт произвольных иконок и JSON-темы оформления — следующий этап.
- **Анимация ярлыка**: Android не поддерживает живые launcher-иконки, поэтому
  анимация эксклюзивных иконок живёт только внутри приложения (выбор иконки и интро).
- **ANC других наушников**: универсального протокола нет. Для Arctis Nova Pro управление
  ANC идёт через SteelSeries; ONYX показывает медиа-контроль и батарею.
- **BPM-синхронизация текста** без таймкодов исследована, но не внедрена: нужен надёжный
  beat-детектор и проверка на реальных треках.
- Управление ANC/батареями — только для Galaxy Buds. Остальные наушники — стандартный
  Bluetooth-аудиовыход; заряд показывается, если система транслирует его в BATTERY_LEVEL_CHANGED.
- Протокол Buds неофициальный: прошивки могут менять смещения полей. Если батареи/режим
  показываются неверно — пришли лог, поправим offsets в `BudsClient.parseStatus`.
- Spicy Lyrics — сторонний catalogue; при недоступности API остаются Musixmatch/Spotify/LRCLIB.
- Spotify color-lyrics может требовать client-token веб-плеера; при отказе используется LRCLIB.
